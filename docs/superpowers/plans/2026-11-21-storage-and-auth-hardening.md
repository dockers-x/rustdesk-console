# 存储配置与认证加固实施计划

目标是让录像和自动备份复用存储配置项，并在同一版本修复 TOTP 重放、种子明文存储和远程备份明文归档。

- [x] 存储配置从客户端设置独立。录像单选并持久化写入时的配置项，自动备份在系统设置多选。验证旧数据库、旧录像、切换中的上传和单目标失败。
- [x] 在 Console 持久化每个账号最近消费的 TOTP 时间步。登录、绑定和取消绑定共用账号锁和时间步规则。验证同一时间步的一次性与不同时间步的正常使用。
- [x] 用独立的文件密钥和 AES-256-GCM 加密 TOTP 种子，迁移现有数据。验证重启、恢复、缺密钥和错误密钥。密钥独立保管。
- [x] 自动、手动及运维命令的远程备份使用 age 公钥加密。在同一快照的各目标上传间复用密文，并验证无公钥时拒绝上传、独立目标失败、正确私钥恢复。
- [ ] 完成回归、浏览器自测及归档验证后先发布 Console，再固定其镜像摘要构建 S6。保留此前恢复的 S6 容器健康检查。

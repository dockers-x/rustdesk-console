# 自有签名客户端与增量兼容性验收

本轮不修改客户端仓库及 shared 子模块。客户端协议基线和构建边界见双语自签指南。

## 审查与验证

- 独立审查后端的管理员授权、开关门禁、原子持久化、密钥配对、私钥脱敏和客户端签名格式，无剩余阻断项。
- 修复前端导入失败时 AxiosError 保留私钥请求体的问题：只让净化后的错误文字进入 mutation 缓存。
- 保存草稿时禁用编辑区，避免请求期间新增编辑被响应覆盖；功能状态重新拉取时不依据旧关闭缓存提前跳转。
- Console workspace：216 项 Rust 测试通过；Web：6 项测试及 TypeScript/Vite 构建通过。普通 Clippy 通过，保留已有 12 项生产/13 项测试风格警告，不顺带清理。
- 临时独立数据库上的真实管理界面验收：默认隐藏、开启后显示、一键生成、错误导入拒绝、有效导入清空私钥输入、草稿保存、签名下载、PNG 校验及下载、双语文档。
- 用独立 Node Ed25519 验签确认浏览器下载的 attached signature 有效；生成文件权限为 0600。
- 关闭后菜单隐藏，直达页面跳回系统设置；generate/sign/profile/catalog 请求均返回 403。
- 响应式覆盖 320/390/720/768/1024/1440px、中英文、深浅色及四个分类，共 96 组；无页面横向溢出。修复暗色 Logo 预览空态对比度。

## v0.2.38 密钥备份语义

以上验收记录对应此前版本。v0.2.38 按新增需求调整生成响应：服务器先自动保存新密钥，再仅在本次管理员生成响应中返回新私钥，前端立即发起密钥对 JSON 下载，不把私钥保留在 query 或 mutation 缓存中。设置读取、导入和签名下载仍不返回私钥，未新增读取已有私钥的接口。

本次增量独立验证：216 项 Rust 测试、7 项 Web 测试及构建通过；后端新增响应的独立复审无阻断项。真实浏览器点击生成并下载 JSON，独立 Node 从 seed 派生公钥，确认公私钥匹配且与服务端保存值完全一致；随后读取设置无私钥、页面私钥输入为空且未展示私钥。未把这次管理员页面测试当作实际客户端构建或远程会话验收。

该下载文件未加密，必须由管理员限制访问并转存加密离线备份，不能随客户端或品牌资源分发。生成响应带有 `Cache-Control: no-store`，但这不替下载文件提供加密或文件系统权限保护。完整服务端 feature 文件的备份恢复方法仍保留，可同时恢复已保存的预置配置和功能开关；一次性密钥对备份只用于重新导入密钥。

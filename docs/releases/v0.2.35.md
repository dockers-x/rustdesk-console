# v0.2.35

本版本包含 v0.2.34 的全部 API 兼容性、安全修复与管理界面改进，详见 `docs/releases/v0.2.34.md`。

- 修复发布流水线和 Docker 构建中的依赖安装失败：统一使用 pnpm 10.34.0，并严格按仓库锁文件安装。
- Docker 构建同时执行 TypeScript 检查，避免只打包而漏过类型错误。
- v0.2.34 的发布构建在前端依赖安装阶段失败，没有生成发布包或镜像；保留原标签，不覆盖已有版本。

升级要求与功能边界沿用 v0.2.34：不需要定制客户端；Switch Sides 授权需要配套 hbbs；WebRTC LocalConfig 开关仍由客户端设置。本版本不承诺完整 Pro 等价、连接 ACL 或网络侧即时撤销。

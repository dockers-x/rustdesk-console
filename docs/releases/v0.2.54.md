# v0.2.54

- 「系统运维」新增「存储配置」，可建立本地、S3 和 WebDAV 配置项。录像和自动备份可直接打开配置项库。
- 录像页可单选存储配置项。切换位置影响新录像，已有录像仍用其写入时的配置。
- 「系统设置」新增「自动备份」标签页，支持多选 S3 和 WebDAV 配置项、修改备份间隔及立即备份。

- TOTP 验证在各登录入口共用账号时间步，一次验证码最多成功使用一次。数据库中的已有 TOTP 种子在升级时加密，恢复数据库时请一并还原独立的 `data/totp.key`。
- 远程备份使用同一份 age 密文上传到所有目标。升级后请为现有远程备份补充 age 公钥。

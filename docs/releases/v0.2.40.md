# v0.2.40

## 开发者接入

- 新增独立“开发者接入”分类：API 密钥、SDK 与示例、OpenAPI 接口文档。支持中英文，不依赖自有签名客户端开关。
- 密钥按账户归属、权限范围和有效期授权；完整值只在创建时显示一次，服务端仅保存 SHA256 哈希与展示前缀。支持即时撤销，默认只读权限和 90 天有效期。
- 每次 API 请求重新检查账户是否存在、启用、需要改密及管理员角色。普通用户仅访问自己的设备和个人通讯录，管理操作仍需管理员及匹配 scope。
- 新增 `/api/v1` 的 16 项类型化管理操作，覆盖账户资料、设备、用户、设备组、策略及个人通讯录；具有有界分页和真实 HTTP 错误状态，不返回密码哈希、TOTP 秘密或签名密钥。
- 公开 `/api/v1/openapi.json`，内置网页展示接口、权限范围和管理员限制，支持下载；提供中英文接入说明。
- 三个 v0.1.0 SDK 位于 `lib-x/rustdesk-console-sdk-rs`、`lib-x/rustdesk-console-sdk-go`、`lib-x/rustdesk-console-sdk-ts`。Rust crate 为 `rustdesk-console-sdk`；TypeScript 通过 GitHub 安装，不表示 npm registry 发布。

## 验证与升级

- Rust workspace 241 项测试、Web 7 项测试、Web 生产构建通过。三种 SDK 各完成 16 项真实接口调用及 401/403/404 错误验证。
- 新增 `developer_keys` 表；数据库迁移 274 为设备组增加默认空的 `note` 列，保留旧数据。升级前请备份数据库与配置；回滚二进制前不要删除新增列或已有设备组数据。
- 原有客户端登录、后台会话和部署协议保持不变，API 密钥不能代替这些凭据。没有修改 RustDesk 客户端或 hbbs/hbbr 协议。
- 发布顺序：Console 镜像构建并核验成功后，再发布固定该镜像 digest 的 rustdesk-server。

# v0.2.61

- 设备详情新增活动时间线，可查看近 7、30 或 90 天的上下线变化和连接审计。升级后开始记录状态变化，离线状态由心跳超时推断。
- 自签名客户端新增可独立开关的下载门户，可分享或撤销按平台和架构列出的预构建安装包，页面显示发布者提供的 SHA-256。
- 设备准入支持一次性入网码和二维码。入网码 10 分钟有效，可兑换 RustDesk 配置，设备继续按现有准入策略审批。
- 设备详情可以保存 MAC 并发送 Wake-on-LAN 唤醒包。查到厂商时会显示名称，设备上线以心跳为准。
- 客户端设置可为单台设备创建带有效期和次数限制的访客链接。设备密码或现场批准仍然生效，撤销链接会断开活动访客会话。
- 封禁列表支持从设备列表选取 ID，也支持精确 IP 和 IPv4、IPv6 CIDR，并显示 HBBS 与 HBBR 的同步状态。
- 数据库升级至 schema 292。

## 部署

- Wake-on-LAN 通过 `wake-on-lan.source-cidr` 指定 Console 的本机 IPv4 地址和网段前缀。部署网络需能把广播送到目标设备。
- 访客会话默认关闭，使用配套 S6 和内置访客查看器。Console 设 `RUSTDESK_API_APP_WEB_GUESTS=true`，HBBS 设 `RUSTDESK_GUEST_RELAY_ADDRESS` 为同机 HBBR 对设备公布的地址，Console 和 HBBS 共用 `RUSTDESK_API_SECURITY_HBBS_ADMISSION_TOKEN`。反向代理须接通 `/api/web-guests/relay` 的 WebSocket。
- 封禁列表通过共享准入令牌同步到配套 S6。设备 ID 规则拦截 HBBS 注册及新连接，网络规则匹配 HBBS/HBBR 连接来源。页面显示各进程是否已应用当前规则。

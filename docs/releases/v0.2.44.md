# v0.2.44

## 在线状态

- 撤回 v0.2.42 对原版客户端上报的默认拦截，恢复心跳更新、设备信息上报、集中策略同步和远控审计，修复设备在线但控制台显示离线的问题。
- 保留设备归属、分组、策略和地址簿的写入保护，以及 hbbs 连接授权检查，不要求修改 RustDesk 客户端。

## 升级提示

默认配置已恢复 `security.allow-legacy-device-reports: true`。如果已有配置文件或环境变量显式设为 `false`，请删除该覆盖或改为 `true` 后重启 Console；对应环境变量为 `RUSTDESK_API_SECURITY_ALLOW_LEGACY_DEVICE_REPORTS`。

原版客户端上报不带认证凭据，仍应限制入口，不能作为可信设备认证或不可抵赖审计。需要严格拒绝匿名上报的部署仍可显式关闭兼容选项。详细边界见[安全升级说明](../security-upgrade.zh-CN.md)。

## 验证与边界

Rust workspace 262 项测试、Web 7 项测试、TypeScript 检查和前端生产构建通过。隔离网络中的真实 Console 进程确认默认配置接收 sysinfo 和 heartbeat、更新数据库在线时间且不改变设备归属，显式关闭兼容后返回 401。未执行线上探测或真实远控会话验收。

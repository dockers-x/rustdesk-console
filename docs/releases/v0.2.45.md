# v0.2.45

## 认证与审计

- 密码、验证码、TOTP、OIDC、会话签发与撤销均可通过结构化日志追踪。代理和 Console 可用同一个请求 ID 关联，认证结果同时记录业务码。
- 管理员须使用 TOTP。支持受限注册流程、OIDC 本地补验和主机端恢复。密码验证共用来源和账号限流，管理会话有效期最长 12 小时。
- 会话列表只显示元数据。会话和成功登录记录一起提交，改密和 TOTP 变更同时撤销已有会话与挑战。
- 示例 Compose 只向回环地址发布 API。镜像记录源码 revision，Console 启动时记录版本，加载 WebClient v2 时记录外部 ZIP 的 SHA-256。

## 地址簿

- 修复原版 RustDesk 客户端添加设备后无法同步旧版地址簿的问题。[#10](https://github.com/dockers-x/rustdesk-console/issues/10)

## 升级

管理员需重新登录。尚未绑定 TOTP 的账号须先从 Console 完成绑定。需要本地二次验证的 stock RustDesk 用户可使用密码登录，或通过 Console 完成 Web SSO 授权。原版客户端心跳、设备信息和审计上报继续按现有兼容配置工作。

安全日志以 JSON 输出到 stdout。建议在升级时配置容器外日志归集，并检查反代的访问控制与请求 ID。更多细节见[安全升级说明](../security-upgrade.zh-CN.md)。

# v0.2.42

## 安全修复

- 系统信息上报不再修改设备归属、分组、策略或地址簿；账号登录和退出不再凭客户端 UUID 改变设备归属。
- 新增与配套 Server v0.2.44 的目标设备授权检查：普通用户可连接自己的设备，管理员可连接已登记且启用的设备。账号禁用、会话撤销和设备停用会阻止新的普通连接协调请求。
- 修复审计设备标识不一致和跨设备备注修改，录像写入及删除要求管理员凭据；WebClient 共享链接取回凭据时检查当前账号和设备权限。
- 修复转发 IP 信任边界，取消仅凭 ID/UUID 豁免登录设备验证，登录验证码实行账号额度和单次使用，登录 token 增加独立随机值。

## 后台设置

管理员可在“系统设置 → 安全”关闭或开启用户注册，保存后立即生效；同时约束密码注册与 OAuth 新账号自动创建，已有账号仍可登录。

## 升级提示

先升级 Console，再升级配套 Server。强制登录的 hbbs 需要配置 Console 地址和共享 JWT 密钥；查询失败时拒绝连接。普通用户仍可使用 WebClient，但地址簿共享不等于设备连接授权，IP 直连和已建立会话不覆盖。

原版客户端的 heartbeat、sysinfo 和审计不带认证凭据。本版本默认拒绝匿名上报，因此默认不再更新原版客户端在线状态、同步策略或接收远控审计。可信网络部署可显式开启 `security.allow-legacy-device-reports` 恢复这些上报；兼容模式中的 ID、UUID、nonce 不提供可信设备认证，且不会恢复预设字段的管理写入。

没有修改 RustDesk 客户端，没有新增客户端设备签名能力，也未据此确认此次异常事件的具体入侵路径。详细配置和边界见 [安全升级说明](../security-upgrade.zh-CN.md)。

# v0.2.52

- 连接审计支持关键词、日期区间、耗时和备注。连接及文件审计支持按当前筛选导出 CSV。
- 设备准入增加来源用户组到目标设备组的单向连接授权。可用账号和设备 ID 预览配套 HBBS 的授权判断。
- 支持运行中创建 SQLite 一致性快照。管理员可在诊断页一键备份，或设定间隔自动上传到多个 S3 和 WebDAV 目标。单个目标失败时，其他上传继续执行。
- 诊断页识别配套 S6 的 HBBS/HBBR 就绪接口，单独部署时保留命令端口检查。
- 登录页移除功能列表，并在系统允许动效时展示轻量背景动画。
- Linux amd64 和 arm64 发布包附带 SHA-256 校验文件。

镜像提供 `czyt/rustdesk-console:v0.2.52` 和 `ghcr.io/dockers-x/rustdesk-console:v0.2.52`。

# v0.2.36

## 自有签名客户端（默认关闭）

- 系统设置新增功能模块开关。启用后显示独立的密钥与签名、品牌与构建、预置选项和文档页面；关闭后隐藏专属入口，后端拒绝相关操作。
- 管理员可一键生成 Ed25519 密钥对，或导入标准 Base64 seed32 / libsodium secret64。密钥独立存储，Unix 文件权限为 0600、目录为 0700；私钥不通过 API 回显或导出。
- 保存配置草稿并下载与当前客户端读取器匹配的 `custom.txt`，支持应用名称、6 项客户端限制和 174 项源码分类选项的默认值、覆盖值。
- PNG 品牌资源可在浏览器本地预览、下载，用于用户 fork 的编译期资源替换，不上传服务器，不伪装为运行时 logo 下发。
- 内置中英文指南，覆盖一键生成、密钥备份恢复、替换验签公钥、自行构建、签名及配置部署。

官方原版客户端不信任自有公钥；用户须在自己的 fork 中替换配置验签公钥并自行构建。本功能不是官方签名、商业授权或在线客户端构建服务。签名不加密配置，关闭功能也不会撤销已下载配置或已分发客户端的公钥。

## 标准客户端兼容性

- 用户及设备目录支持在分页前过滤真实状态；管理员设备目录包含跨组和未分配设备，普通用户的可见范围不变。
- 设备目录返回实际备注与状态，可访问设备组返回准确分页和总数。
- 集中策略新增 KCP 拥塞控制、Android 软件编码半分辨率、Windows SYSTEM 服务录制目录，明确平台与作用范围。

默认部署仍兼容标准客户端。WebRTC 等 LocalConfig 选项不作为心跳策略下发；可由客户端本地设置，或在可选自签配置中预置。本版本不承诺完整 Pro 等价、实时连接 ACL 或自动录制上传。

## 升级与发布

已有配置无需迁移，自签功能不会自动启用或生成密钥。密钥和草稿位于 `<config-parent>/features/self-signed-client.json`，部署及备份须保留此目录。

配套 rustdesk-server 在本版 Console Docker 构建成功并核验后发布，避免 S6 组合镜像引用旧 Console。

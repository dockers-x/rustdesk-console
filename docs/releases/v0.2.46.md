# v0.2.46

## 设备通知

- 新增 ntfy、Bark 和 Server 酱，同一个上线事件可以发到多个通知渠道。Server 酱会按 SendKey 自动选用 App 或微信推送。
- 每条规则可以选择通知模板。在模板管理中编辑标题和正文，并从变量选择器插入设备信息。支持在保存前测试，也可以在列表中测试已保存的规则。
- 投递会记录每个渠道的结果，并在 Console 重启后继续处理未完成的任务。更多配置细节见[设备通知说明](../notification-routing.zh-CN.md)。

## Console 界面

- Cloudflare Kumo 更新至 2.19.0。模板编辑器沿用控制台的输入、选择和弹窗组件。

## 升级

容器镜像直接使用该版本对应架构的发布包二进制。

本版包含 [v0.2.45 的认证与审计改动](v0.2.45.md)，包括管理员 TOTP、结构化安全日志及原版 RustDesk 地址簿同步修复。已有 Webhook 保留原设置并使用内置模板。请将经过 HTTP 重定向的规则改为最终接收地址。

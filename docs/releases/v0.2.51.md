# v0.2.51

- 新增本地运维命令，可查看版本、校验配置、检查数据库版本和单独执行迁移。启动时会拒绝使用比当前程序更新的数据库。密码恢复支持标准输入和受保护的密码文件。
- 控制台、登录、连接和文件审计可分别设置保留期，并可开启定时清理。保留现有的预览、手动清理和活动会话及关联录像保护。
- Geo 路由页可用两端的 IP 试算当前 HBBS 规则，查看命中的规则、所选中继及回退原因。结构化试算需要配套新版 HBBS。
- 新增委派管理角色。可授权指定用户组和共享地址簿集合，委派管理员在独立页面管理授权范围内的普通账号状态及地址簿资料。
- 设备列表在 ID 旁显示在线状态，点击 ID 可查看设备详情。登录日志把浏览器和平台摘要放在列表，完整原始信息可在详情中查看。
- 文件审计展示设备、传输方向、路径、数量及可用的文件大小。支持方向和路径筛选，并可展开客户端上报的文件明细。
- 登录日志、连接审计、文件审计、活跃连接和录屏记录的设备 ID 可以复制。具备地址簿或设备列表访问权限的管理员可以直接打开对应条目。
- 加入 Console 默认 Logo 和多尺寸浏览器图标。上传的站点 Logo 优先显示。

Docker 镜像包括 `czyt/rustdesk-console:v0.2.51` 和 `ghcr.io/dockers-x/rustdesk-console:v0.2.51`，支持 amd64 和 arm64。

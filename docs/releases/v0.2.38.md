# v0.2.38

包含 v0.2.37 的 Docker 内置指南修复，以及此前自有签名客户端和标准客户端兼容性改进。

## 一次性密钥对备份

- 管理员生成 Ed25519 密钥对后，服务器自动保存新密钥；页面随即发起 `self-signed-client-keypair.json` 下载，包含公钥、新私钥及指纹。
- 只有生成响应返回该次新私钥，并带有 `Cache-Control: no-store`。后续设置读取、密钥导入和签名配置下载不回显私钥，未新增导出已有服务端私钥的接口；前端不把生成的私钥保留在 query 或 mutation 缓存中。
- 下载文件是未加密的私钥备份，须限制访问并转存加密离线存储，不能放入客户端发布包、公开仓库或共享目录。HTTP 不缓存不等于文件加密或安全的本地权限。
- 下载被阻止或备份丢失时，可以按双语指南备份服务器现有 feature 文件；不要为了重新取得旧密钥而点击生成，生成会替换密钥。密钥对 JSON 可用于重新导入公私钥，但不包含预置配置或功能开关；完整 feature 文件的服务端备份恢复流程保留。

## 边界与升级

自有签名功能仍默认关闭，已有配置无需迁移。普通客户端接口和功能开关语义不变。官方客户端仍不信任自有签名，用户须自行替换源码验签公钥并构建；本功能不提供官方签名或在线客户端构建服务。

配套 rustdesk-server 仍须在本版 Console Docker 构建成功并核验后发布。

# v0.2.34

1. **客户端审计**：对齐当前检出的 RustDesk 1.5.1 源码协议，修复成功上报仍重试的问题，增加事务去重和可查询的告警记录，并隔离不同设备的同号连接。
2. **地址簿与策略**：标签改名、删除同步更新所属地址簿的设备引用，补充 ID 白名单、范围违规告警及断连选项。
3. **切换控制方向**：新增签名授权转发，需要配套 hbbs 支持，并保留客户端最终的一次性免密校验，不需要定制客户端。
4. **账户与上传安全**：禁用账户立即失去 Console API 访问权，修复登录封禁与重置密码保护，并限制新上传为常见位图格式、隔离历史上传内容的脚本权限。
5. **录制与运维**：录制删除失败不再假报成功或丢失元数据，修复并发保存配置丢失、服务端命令响应截断及极端分页溢出。
6. **部署兼容性**：生成 Windows 合法的编码配置文件名，修复数据库凭据中的 URL 特殊字符和非法时长配置处理。
7. **管理界面**：改善导航上下文、概览层级和空状态，修复窄屏及短视口弹窗裁切，保持中英文、深浅色与减少动态效果设置可用。

## 升级说明

- 首次启动自动创建新增审计表，不改变旧表字段；审计回执和日志一样会持续占用存储。
- 重置密码挑战在提交一次后失效，输错验证码需重新申请。
- Switch Sides 授权要求 Console 与配套 hbbs 共享可信 loopback 控制通道，独立 hbbs 实例不共享临时授权。
- WebRTC 的 LocalConfig 开关仍由客户端设置，不能借用现有策略接口下发。
- 本版本不承诺完整 Pro 等价、连接 ACL 或网络侧即时撤销，具体边界见 `docs/pro-feature-compatibility.md`。

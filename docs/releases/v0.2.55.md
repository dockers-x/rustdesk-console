# v0.2.55

- 资源列表的筛选项现在有常驻标签。输入文字时会合并连续查询，清除筛选后焦点返回首个字段。查询失败可直接重试，翻页和筛选后的记录数更易辨认。
- 登录页和控制台顶部都可以直接选择简体中文、English 或 Русский。总览、设置和表单统一了面板层次、主操作和对齐方式。窄屏显示当前页面名称，侧栏支持键盘焦点循环。
- 创建及编辑资源时可按 Enter 提交。键盘导航即时切换，弹窗和菜单支持系统的「减少动态效果」设置。
- 总览在数据库内统计设备和在线数量，仅向服务端返回按操作系统分组的汇总。活跃连接心跳按批写入，同一份快照的所有批次在一个事务内提交。
- 数据库升级至 schema 283，为设备 ID、UUID、在线时间及活跃连接的设备和更新时间建立索引。首次升级会在现有数据上创建索引，大型实例请预留维护时间。回退至 v0.2.54 时需恢复升级前的数据库备份。

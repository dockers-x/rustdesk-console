# v0.2.41

## 管理界面

- 新增俄语界面及开发者接入文案，支持按浏览器语言自动选择，并可通过顶部按钮循环切换 English、Русский、中文。
- 修复管理弹窗向上偏移、标题和首行字段被裁切的问题，小屏幕下弹窗内容可滚动，底部操作按钮保持可见。
- 修复客户端设置、WebClient 分享、一次性凭据和个人 2FA 信息在局域网 HTTP 页面无法复制的问题，浏览器不支持 Clipboard API 或拒绝访问时尝试兼容复制方式。

以上改动来自 PR #7，感谢 @Lyapnev。

## 验证与边界

- Rust workspace 241 项测试、Web 7 项测试及生产构建通过，已在浏览器验证三语言切换与持久化、开发者接入俄语文案、桌面及小屏弹窗，以及 Clipboard API 不可用时的复制。

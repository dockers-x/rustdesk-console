# v0.2.58

- 在「个人中心 → 安全」查看可信浏览器、信任日期、最近使用和到期时间。可撤销单条或全部记录，并选择同时结束关联会话。
- 在「系统设置 → 登录安全」设定新授权浏览器的信任期限为 7 天或 30 天。登录页可选「本次使用验证码」；登录日志标明可信浏览器登录，控制台审计记录信任和撤销操作。
- 「要求管理员启用 2FA」默认开启。关闭后，如果全站和该账号均未强制 2FA，管理员可在个人中心输入当前验证码后停用验证器。
- 原生客户端的登录会话查询遇到数据库临时错误时返回 HTTP 503，使客户端保留本地会话。真正失效的会话仍返回 HTTP 401。
- 「已验证的登录设备」显示账号验证记录。「我的设备」提供使用 RustDesk 客户端建立远控信任的说明。
- 数据库升级至 schema 284。升级后需要重新验证一次并确认信任当前浏览器，才能将它加入可撤销的列表。回退旧版时请恢复升级前的数据库备份。

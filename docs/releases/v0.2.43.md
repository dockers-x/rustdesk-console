# v0.2.43

## WebClient

- `data/web.zip` 同时支持根目录直接包含 `index.html` 和外层带 `web/` 目录两种结构，页面及资源均通过 `/webclient2/` 访问，两种入口同时存在时优先使用根目录。

## 升级提示

升级 Console 并重启服务后会重新加载 `data/web.zip`，上述两种结构都无需重新打包。

此前版本的安全配置要求仍然适用，详见[安全升级说明](https://github.com/dockers-x/rustdesk-console/blob/v0.2.43/docs/security-upgrade.zh-CN.md)。

## 验证与边界

两种 ZIP 结构的页面和 JavaScript 资源经过本地 HTTP 路由测试，另有入口优先级、路径穿越拒绝和临时目录清理测试；未执行真实远控会话验收。
